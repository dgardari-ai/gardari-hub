# Хаб Гардари

Центральная авторская страница с семью направлениями и интерактивной навигационной сферой.

Рабочая версия сайта: **1.0** (принята 24 октября 2026 года; перенос в разработку 25 октября).

Открыть локально: `python3 -m http.server 4173` в корне репозитория; адрес `http://127.0.0.1:4173/`.

Исходник: `index.html`, `styles.css`, `app.js`, `assets/`. JavaScript без сборки и внешних зависимостей; шрифты и изображения находятся локально. Публикация: GitHub Pages (временно). Домены старого сайта и приватного Sites не изменены.

Ссылки ряда направлений — пилотные, требуют предметной проверки перед основным запуском на gardari.art.
